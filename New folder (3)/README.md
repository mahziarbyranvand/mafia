# MAFIA ARENA — نسخه‌ی آنلاین (بازیکن واقعی + ویس چت)

## فایل‌ها (همه را کنار عکس‌ها و صداهای بازی در یک پوشه بگذارید)
mafia.html · mafia-online.js · mafia-pro.css · server.js · game.js · package.json

## اجرا روی کامپیوتر خودتان
1. Node.js (نسخه ۱۶ به بالا) را نصب کنید: https://nodejs.org
2. پوشه‌ی بازی را در VS Code باز کنید، Terminal ← New Terminal
3. یک بار:  `npm install`
4. هر بار:  `node server.js`
5. در مرورگر:  http://localhost:3000   (با Live Server باز نکنید؛ سرور خودش فایل‌ها را می‌دهد)

## بازی با دوستان از راه دور (ویس چت به HTTPS نیاز دارد)
مرورگرها روی آدرس http (غیر از localhost) میکروفن نمی‌دهند. دو راه:
- **موقت:** `npx cloudflared tunnel --url http://localhost:3000` (یا ngrok) → آدرس https که می‌دهد را برای بقیه بفرستید.
- **دائمی:** آپلود پوشه روی یک هاست Node با HTTPS (مثلاً Render، Railway، Fly.io): Build = `npm install` ، Start = `node server.js`. متغیر PORT را خودشان می‌دهند.

## قوانین ویس و شروع بازی (در سرور اجرا می‌شود)
- هر بازیکن بعد از ورود به لابی **۱۵ ثانیه** برای تأیید میکروفن دارد؛ اگر ندهد یا رد کند از اتاق حذف می‌شود.
- بازی فقط وقتی شروع می‌شود که اتاق **پر** باشد (۱۰ یا ۱۶ نفر) و ویس **همه** تأیید و وصل شده باشد؛ همه با هم وارد بازی می‌شوند.
- در بازی فقط نوبت صحبتِ هر نفر میکروفنش باز است.
- روم عادی/VIP: سرور خودش بازیکن‌ها را در یک اتاق عمومی جمع می‌کند. «ساخت لابی»: اتاق خصوصی با کد (و رمز اختیاری)؛ فقط سازنده می‌تواند بازیکن را حذف کند.

## محدودیت‌های نسخه‌ی اول
- ویس مستقیم بین بازیکن‌هاست (WebRTC با STUN گوگل). پشت بعضی شبکه‌ها/مودم‌ها بدون سرور TURN وصل نمی‌شود: `window.MF_ICE = [...]` را در html تنظیم کنید.
- اتاق ۱۶ نفره ویس سنگین‌تری دارد (هر نفر ۱۵ اتصال).
- اگر کسی وسط بازی خارج شود دوباره وارد همان بازی نمی‌شود.
- حساب کاربری، سکه، بن و پنل مدیریت هنوز داخل مرورگر هر نفر ذخیره می‌شود (سمت سرور نیست).
